Заранее не знаем, сколько чисел введёт пользователь? `int data[100]` может не хватить, а `int data[1000000]` — пустая трата памяти. **Динамическая память** выделяется во время работы программы — ровно столько, сколько нужно.

| | Стек | Куча |
|---|---|---|
| Что там | локальные переменные функций | то, что выделили сами |
| Управление | автоматическое | ручное: `malloc` / `free` |
| Время жизни | пока работает функция | до вызова `free` |

**Правильный порядок работы с `malloc`** (нужен `#include <stdlib.h>`):

```c
int *ptr = malloc(n * sizeof(int));   // выделить память под n int
if (ptr == NULL)                       // обязательно проверить
{
    return 1;
}
ptr[0] = 10;                           // пользоваться как массивом
free(ptr);                             // обязательно освободить
ptr = NULL;                            // хорошая привычка
```

`malloc` возвращает адрес блока или `NULL`, если память не выделилась. Память **не обнулена** — там «мусор».

- `calloc(n, sizeof(int))` — то же, но память заполнена **нулями** (удобно для счётчиков).
- `realloc(ptr, new_size)` — меняет размер блока. Может вернуть **новый адрес**, а при ошибке — `NULL`, поэтому результат сначала кладут во временный указатель:

```c
int *temp = realloc(ptr, new_capacity * sizeof(int));
if (temp == NULL)
{
    free(ptr);
    return 1;
}
ptr = temp;
```

**Типичные ошибки:** забыть `free` (утечка памяти); использовать память после `free` (висячий указатель); вызвать `free` дважды; освободить то, что выделено не через `malloc`/`calloc`/`realloc`.
