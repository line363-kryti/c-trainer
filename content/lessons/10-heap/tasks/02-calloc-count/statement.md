*Лекция советует `calloc` для счётчиков — вот такая задача.*

Пользователь вводит цифры от 0 до 9. Посчитай, сколько раз встретилась каждая. Массив из 10 счётчиков выдели через `calloc` — он сразу заполнится нулями.

**Ввод:** число `n` (`1 ≤ n ≤ 1000`), затем `n` цифр через пробел.

**Вывод:** для каждой цифры, которая встретилась хотя бы раз, по возрастанию — строка «цифра количество».

**Пример**

| Ввод | Вывод |
|------|-------|
| `6`<br>`3 1 3 9 3 1` | `1 2`<br>`3 3`<br>`9 1` |
