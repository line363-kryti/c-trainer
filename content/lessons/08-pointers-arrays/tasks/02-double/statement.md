Функция получает указатель на первый элемент — значит, может **менять сам массив**.

Допиши функцию `double_all`, которая умножает каждый из `n` элементов на 2. `main` выводит массив после вызова.

**Ввод:** число `n` (`1 ≤ n ≤ 100`), затем `n` целых чисел, каждое по модулю не больше 1 000 000.

**Вывод:** элементы после удвоения, по одному на строке.

**Пример**

| Ввод | Вывод |
|------|-------|
| `3`<br>`1 -2 5` | `2`<br>`-4`<br>`10` |
