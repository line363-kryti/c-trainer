Элементы массива лежат в памяти **подряд**, один за другим. У каждого есть адрес: `&numbers[0]`, `&numbers[1]`…

**Имя массива в выражениях превращается в указатель на первый элемент.** Поэтому можно написать просто:

```c
int numbers[] = {10, 20, 30};
int *p = numbers;     // p указывает на numbers[0]
```

**Двигаемся по массиву:** `*p` — 10, `*(p + 1)` — 20, `*(p + 2)` — 30. Запись `numbers[i]` — это то же самое, что `*(numbers + i)`. Это одна из фундаментальных связей массивов и указателей в C.

**Что значит `p + 1`?** Не «плюс один байт», а «следующий объект того типа, на который указывает `p`». Для `int *` — следующий `int`, для `char *` — следующий `char`. Шаг зависит от типа.

**Массив — это не указатель.** Просто имя массива в большинстве выражений превращается в указатель. Разницу видно через `sizeof`:

```c
int numbers[3] = {10, 20, 30};
int *p = numbers;

printf("%zu\n", sizeof(numbers));  // размер всего массива
printf("%zu\n", sizeof(p));        // размер указателя
```

Поэтому функция, которая получает массив, на самом деле получает **указатель на первый элемент** — и размер нужно передавать отдельно:

```c
int sum(int *p, int n);   // вызов: sum(numbers, 5)
```
