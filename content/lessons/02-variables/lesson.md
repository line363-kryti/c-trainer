**Переменная** хранит данные: возраст, количество, результат вычисления.

```c
int age = 20;   // тип int, имя age, значение 20
```

**Типы данных** — какие данные хранит переменная:
- `int` — целые числа: `int temperature = -5;`
- `double` — числа с дробной частью: `double height = 1.69;`
- `char` — один символ: `char grade = 'A';`

`'A'` и `"A"` — не одно и то же: одинарные кавычки — один символ, двойные — строка.

**Объявление и присваивание.** `int x;` — объявили переменную. `x = 10;` — записали значение. Можно сразу: `int x = 10;`. Значение переменной можно менять: после `x = 20; x = 50;` в `x` лежит 50.

**Арифметика:** `+` `-` `*` `/` и `%` (остаток от деления). Если оба числа `int`, деление целочисленное: `10 / 3` даёт `3`, а `10 % 3` даёт `1`. С `double` получится примерно `3.333333` (выводится через `%f`).

```c
int a = 10;
int b = 3;
printf("%d\n", a / b); // 3
printf("%d\n", a % b); // 1
```

`%d` в `printf` — «здесь вывести целое число `int`».

**Ввод.** `scanf` получает данные от пользователя:

```c
int age;
scanf("%d", &age);
printf("Your age is %d\n", age);
```

`%d` говорит `scanf`, что ждём целое число. `&age` — куда записать значение. Почему нужен `&`, подробно разберём в теме про указатели.

> **На сайте:** проверка сравнивает весь вывод программы с ответом, поэтому не выводи подсказки вроде `Enter your age:` — только то, что просят в задаче.
