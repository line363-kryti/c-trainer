То же самое, но числа `a` и `b` вводит пользователь.

**Ввод:** два целых числа `a` и `b` через пробел. `0 ≤ a ≤ 10000`, `1 ≤ b ≤ 10000`.

**Вывод:** пять строк: `a + b`, `a - b`, `a * b`, `a / b`, `a % b`.

**Пример**

| Ввод | Вывод |
|------|-------|
| `10 3` | `13`<br>`7`<br>`30`<br>`3`<br>`1` |
