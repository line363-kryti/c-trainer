**Структура** объединяет несколько связанных данных разных типов в один объект:

```c
struct Student
{
    char name[50];
    int age;
};
```

Это только **описание** типа — самого студента ещё нет. Создаём переменную и обращаемся к полю через точку:

```c
struct Student student;
student.age = 20;
```

**Указатель на структуру** создаётся как обычно:

```c
struct Student *p = &student;
```

Как получить поле `age` через указатель? Сначала `*p` — сама структура, потом `.age` — её поле: `(*p).age`. Писать так каждый раз неудобно, поэтому в C есть оператор **`->`**:

```c
p->age = 21;   // то же самое, что (*p).age = 21
```

Запомнить просто:
- `student.age` — когда есть **сама структура**;
- `p->age` — когда есть **указатель** на структуру.

Структуры часто передают в функции именно по указателю — тогда функция может изменить поля исходного объекта.
