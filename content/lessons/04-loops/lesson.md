Вывести числа от 1 до 100 сотней `printf` нельзя — нужно **повторять действия**.

**while** повторяет блок, пока условие истинно:

```c
int i = 1;

while (i <= 5)
{
    printf("%d\n", i);
    i++;
}
```

Шаг за шагом: `i = 1`, условие `i <= 5` истинно — печатаем 1, `i++` делает `i = 2`, снова проверяем… Когда `i = 6`, условие ложно — цикл заканчивается.

`i++` значит `i = i + 1` — увеличить на один. `i--` — уменьшить на один.

**for** удобен, когда заранее понятно, сколько раз повторять:

```c
for (int i = 0; i < 5; i++)
{
    printf("%d\n", i);
}
```

Три части в скобках: `int i = 0` — начальное состояние; `i < 5` — пока это истинно, выполняем цикл; `i++` — что делать после каждого повтора. Этот цикл напечатает 0, 1, 2, 3, 4.
