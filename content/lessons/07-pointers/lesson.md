Вспомним урок про функции: `change(a)` получает **копию** значения, поэтому `a` в `main` не меняется. Чтобы функция могла изменить саму переменную, ей нужно знать, **где** эта переменная лежит.

**У переменной есть значение и адрес.** Память можно представить как пронумерованные ячейки. Если `int x = 10;` лежит по адресу 1000, то значение `x` — 10, а адрес — 1000.

**`&` — получить адрес:** `&x` — «адрес переменной `x`». Вывести адрес можно через `%p`: `printf("%p\n", (void*)&x);` — конкретное число будет разным при каждом запуске.

**Указатель хранит адрес:**

```c
int x = 10;
int *p = &x;   // p — указатель на int, в нём адрес x
```

**`*` в выражении — разыменование:** `*p` — «объект по адресу из `p`». Через него можно читать и **менять** переменную:

```c
printf("%d\n", *p);   // 10
*p = 50;
printf("%d\n", x);    // 50 — изменили x через указатель
```

| Выражение | Что это |
|---|---|
| `x` | значение переменной (10) |
| `&x` | адрес `x` |
| `p` | значение указателя — адрес `x` |
| `*p` | объект по этому адресу (10) |

Указатель можно перенаправить: после `p = &y;` он указывает на `y`, а `x` не меняется. Указатель — тоже переменная, у него есть свой адрес `&p`.

**Главное правило:** если функция должна изменить переменную, передаём её адрес.

```c
void swap(int *a, int *b)
{
    int temp = *a;
    *a = *b;
    *b = temp;
}

swap(&a, &b);   // передаём адреса, а не значения
```
