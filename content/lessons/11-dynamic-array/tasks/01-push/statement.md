*Динамический массив из лекции.*

В заготовке уже есть структура `DynamicArray`, `array_create`, `array_free` и `array_print`. Допиши `array_push`: если места нет — удвой вместимость через `realloc`, затем добавь элемент в конец. Массив создаётся с вместимостью 2.

Ничего, кроме `array_print`, выводить не нужно.

**Ввод:** число `n` (`0 ≤ n ≤ 1000`), затем `n` целых чисел.

**Вывод:** строка из `array_print`.

**Пример**

| Ввод | Вывод |
|------|-------|
| `3`<br>`10 20 30` | `Array [size=3, capacity=4]: [10, 20, 30]` |
