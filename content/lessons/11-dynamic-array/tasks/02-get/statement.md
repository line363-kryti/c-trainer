В заготовке есть готовый динамический массив с `array_push`. Допиши `array_get`: если индекс за пределами (`index >= size`), верни `-1`; иначе запиши элемент по адресу `out_value` и верни `0`.

**Ввод:** число `n` (`0 ≤ n ≤ 100`) и `n` чисел — элементы массива; затем число запросов `q` (`1 ≤ q ≤ 100`) и `q` индексов (`0 ≤ индекс ≤ 1000`).

**Вывод:** для каждого запроса — элемент с этим индексом или `out of range`.

**Пример**

| Ввод | Вывод |
|------|-------|
| `3`<br>`10 20 30`<br>`3`<br>`0 2 3` | `10`<br>`30`<br>`out of range` |
