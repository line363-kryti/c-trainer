Разберём самую простую программу:

```c
#include <stdio.h>

int main()
{
    printf("Hello, world!\n");

    return 0;
}
```

- `#include <stdio.h>` — подключаем библиотеку с готовыми функциями. Нам из неё нужна `printf` — вывод на экран. «Мне понадобятся инструменты из вот этого набора».
- `main` — специальная функция: когда программа запускается, выполнение начинается с `main`.
- `{` и `}` — начало и конец блока кода. Всё между ними относится к этому блоку.
- `;` — конец инструкции, как точка в конце предложения.
- `return 0;` — `main` заканчивает работу и возвращает операционной системе 0. Это нормальное завершение программы.
- `\n` внутри строки — переход на новую строку.

**Пример.** Каждый `printf` с `\n` на конце выводит отдельную строку:

```c
printf("Julia\n");
printf("I study at ITMO\n");
printf("I am learning C\n");
```
