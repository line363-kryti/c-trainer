Когда программа разрастается до сотен строк, держать всё в `main` неудобно — её разбивают на **функции**.

```c
void printNumber(int x)      // функция с параметром x
{
    printf("%d\n", x);
}

int sum(int a, int b)        // возвращает int, параметры a и b
{
    return a + b;            // результат — вызывающему коду
}

int main()
{
    printNumber(10);         // вызов функции
    int result = sum(10, 20);   // result = 30
    return 0;
}
```

`void` — функция ничего не возвращает. `int sum(int a, int b)`: `int` — что возвращает, `sum` — имя, `int a, int b` — параметры.

**Параметр — это отдельная переменная.** Что напечатает программа?

```c
void change(int x)
{
    x = 100;
}

int main()
{
    int a = 10;
    change(a);
    printf("%d\n", a);
    return 0;
}
```

Напечатает **10**. Функция получает *значение* `a`, внутри появляется свой параметр `x = 10`. `x = 100` меняет только `x`, а `a` в `main` остаётся 10.
