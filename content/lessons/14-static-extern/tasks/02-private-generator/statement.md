Адаптация практики «Static функция» из лекции под один файл.
Допиши приватную `generate_id()`, вызываемую через публичную `get_next_id()`.
Для проверки последовательности ID договоримся: первый ID — 1, следующий на 1 больше.
В каждой итерации `main` запрашивает два ID и выводит их в одной строке.

**Ввод:** n от 0 до 10. **Вывод:** n строк с парами `1 2`, `3 4` и так далее.
При n = 0 ничего не выводи. Реальную приватность имени между файлами проверяй в IDE.
