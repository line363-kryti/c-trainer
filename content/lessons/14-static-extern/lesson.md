`static` вне функции ограничивает видимость имени текущим исходным файлом:
так прячут вспомогательные функции и переменные модуля.
Внутри функции `static` сохраняет значение между вызовами.

```c
void counter(void) {
    static int count = 0;
    count++;
    printf("%d\n", count);
}
/* Три вызова напечатают 1, затем 2, затем 3. */
```

`extern` объявляет переменную, определённую в другом месте. Общее объявление
можно поместить в заголовок, а определение с начальным значением — в один `.c`.

```c
/* globals.h */
extern int error_code;

/* globals.c */
int error_code = 0;
```

Объявление сообщает о существовании переменной, определение выделяет для неё место.
Если определить одну внешнюю переменную в заголовке и подключить его из нескольких
файлов, возможна ошибка `multiple definition`.

Практика лекции предлагает приватную `generate_id()` и публичную `get_next_id()`.
В редакторе проверяется последовательность значений в одном файле; реальную границу
модулей нужно проверить при сборке отдельных `.c` в IDE.
Для поиска проблем лекция предлагает `gcc -Wall -Wextra`, `nm main.o` и `gcc -M main.c`.
