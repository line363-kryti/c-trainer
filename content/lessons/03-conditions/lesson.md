Программа умеет принимать решения: если условие истинно — выполняется один блок, иначе — `else`.

```c
if (age >= 18)
{
    printf("Adult\n");
}
else
{
    printf("Not adult\n");
}
```

**Сравнения:** `==` равно, `!=` не равно, `>` больше, `<` меньше, `>=` больше или равно, `<=` меньше или равно.

**`=` и `==` — не одно и то же.** `x = 10;` — положить 10 в `x`. `x == 10` — проверить, равно ли `x` десяти. Перепутать их — одна из самых частых ошибок.

**Несколько вариантов — `else if`:**

```c
if (x > 0)
{
    printf("Positive\n");
}
else if (x < 0)
{
    printf("Negative\n");
}
else
{
    printf("Zero\n");
}
```

**Логические операции:** `&&` — И, `||` — ИЛИ, `!` — НЕ.

```c
if (age >= 18 && age <= 60)   // возраст от 18 И до 60
if (x == 0 || x == 1)         // x равен 0 ИЛИ 1
```
