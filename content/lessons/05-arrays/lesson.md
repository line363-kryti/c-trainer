**Массив** — несколько элементов одного типа под одним именем. Вместо пяти переменных `a`, `b`, `c`, `d`, `e`:

```c
int numbers[5] = {10, 20, 30, 40, 50};
```

```
  ┌────┬────┬────┬────┬────┐
  │ 10 │ 20 │ 30 │ 40 │ 50 │
  └────┴────┴────┴────┴────┘
    0    1    2    3    4      ← индексы
```

**Индексация начинается с нуля:** `numbers[0]` — это 10, `numbers[4]` — 50. У массива размера 5 допустимые индексы 0–4, а `numbers[5]` — **не** элемент этого массива.

`numbers[1] = 100;` — меняем конкретный элемент с индексом 1. Массив станет `10 100 30 40 50`.

**Массив + цикл:** `i` меняется от 0 до 4, и `numbers[i]` каждый раз — очередной элемент.

```c
int sum = 0;
for (int i = 0; i < 5; i++)
{
    sum += numbers[i];   // то же, что sum = sum + numbers[i];
}
```

**Максимум:** сначала считаем максимальным первый элемент, потом идём по остальным и запоминаем, если нашли больше.

```c
int max = numbers[0];
for (int i = 1; i < 5; i++)
{
    if (numbers[i] > max)
    {
        max = numbers[i];
    }
}
```

Ввод элементов массива: `scanf("%d", &numbers[i]);` внутри цикла.
