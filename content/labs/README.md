# Лабораторные работы

Загружены 6 работ из курса https://laritmo.site/courses/4. Оригиналы: source.md, варианты первых двух: variants.md. Лицензия источника: SOURCE-LICENSE.txt.
Автоматические тесты пока не настроены: tests=[]; API проверки отвечает 409. Этапы — ручные чек-листы требований из оригиналов.
Каждая папка `<slug>` содержит `lab.json`, `statement.md`, `template.c`.
Slug: латинские строчные буквы, цифры и дефисы (до 61 символа).

Поля lab.json: title, order, variant (описание одного конкретного варианта), source,
tests (0–20 пар input/output; пустой список означает отсутствие автопроверки), stages и defense (список вопросов).
Каждый вариант пока оформляется отдельной работой.

Этап: id, title, description (Markdown), hint, tests (необязательно), harness (необязательно).
Без tests этап отмечается вручную. С tests — запускается код ученика на этих тестах.
Если задан harness — main ученика переименовывается в student_main, затем добавляется
проверочная программа с собственным main для вызова конкретной функции.
Harness и эталоны тестов не выдаются при загрузке страницы.
После проверки API показывает ввод, ожидаемый и полученный вывод.

Перед публикацией автор обязан проверить эталон на всех тестах и соответствие исходному заданию.
Автопроверка не доказывает отсутствие утечек памяти и не заменяет защиту.
Результаты этапов привязаны к хэшу кода, изменённый код требует повторной проверки.
Данные пользователей лежат в отдельной таблице lab_progress (миграция 0002).
Обновление: docker compose exec backend alembic upgrade head.
Страницы: /labs.html и /lab.html?lab=<slug>.
